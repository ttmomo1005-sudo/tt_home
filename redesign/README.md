# 作品集改版

个人网站：[ttt.hk.cn](https://ttt.hk.cn)。当前网站使用这一版本；仓库根目录保留原版。

## 运行

在本目录执行：

```sh
npm ci
npm run dev
```

本地地址：http://localhost:5174/。

执行 `npm run build` 生成本目录的 `dist/`，执行 `npm run preview` 预览构建结果。

## 内容

包含七项作品、星空背景、图片相册、项目介绍和赛事视频。私人交易截图及其展示入口已排除，其余作品内容沿用本地改版源码。完整的收录范围见[仓库说明](../README.md#公开文件范围)。
