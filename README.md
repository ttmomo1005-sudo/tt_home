# 童墨晗的个人作品集

个人网站：**[ttt.hk.cn](https://ttt.hk.cn)**

使用 React、TypeScript、Vite 和 Tailwind CSS，展示机器人、硬件产品、微信小程序和 AI 协作项目。

## 两个版本

- 根目录：原版作品集，保留原有页面设计。
- [`redesign/`](./redesign/)：改版作品集，包含七项作品、图文弹窗和赛事视频；当前网站使用这一版本。

## 本地运行

需要 Node.js 22.12 或更新的受支持版本。

原版在仓库根目录执行：

```sh
npm ci
npm run dev
```

打开 http://localhost:5173/。

改版在独立目录执行：

```sh
cd redesign
npm ci
npm run dev
```

打开 http://localhost:5174/。两版均有独立的依赖锁文件。

## 构建与部署

在所需版本目录执行 `npm run build`，生成该目录的 `dist/`。可通过 `npm run preview` 检查构建结果，再将 `dist/` 的内容交给静态网站服务器托管。不要直接双击源码中的 `index.html`。

同步源码到本仓库不触发网站部署；域名的现有托管方式保持独立。

## 公开文件范围

本仓库仅包含网站源码、构建配置、依赖锁文件及审核后的作品媒体。姓名、作品介绍、团队照片和网站备案号属于网页已有的公开展示内容。

证书与私钥、账号和服务器资料、项目记忆与交接文档、个人聊天与交易截图、备份、发布压缩包、开发工具配置、缓存和依赖目录均不收录。改版中关联私人交易截图的展示入口已从仓库副本移除，保留机器鸭项目介绍和产品照片。

`.gitignore` 默认忽略未明确允许的目录与文件。新增公开内容前，请先检查内容，再按需调整允许范围；不要强制加入私人文件。
